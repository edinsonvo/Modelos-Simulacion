# Modelos y Simulación de Sistemas I — Proyecto Integrador

Predicción de la variación mensual del IPC en Colombia por ciudad y grupo de gasto.

El repositorio conserva cada entrega en su propia carpeta:

| Carpeta | Contenido |
|---|---|
| [`fase-1/`](fase-1/) | Análisis exploratorio, modelo inicial y cuaderno reproducible |
| [`fase-2/`](fase-2/) | Scripts reutilizables de entrenamiento y predicción, versionado y Docker |
| [`fase-3/`](fase-3/) | API REST con FastAPI (`/health`, `/predict`, `/train`) |
| [`fase-4/`](fase-4/) | Monitoreo de solicitudes, métricas de operación y política de reentrenamiento |

Cada carpeta incluye su propio `README.md` con las instrucciones de ejecución,
pruebas y verificación correspondientes.
